# Provenance audit of io_death_rates_v4.R

Written 2026-09-28. Script audited (not edited): /home/user/NE-IndOcc-Deaths/scripts/io_death_rates_v4.R (244 lines). Question asked of every rule: which rule did the Nebraska DHHS occupational health team, CDC/NIOSH, CSTE or Massachusetts DPH already use, and did v4 copy it, change it, or make it up?

Verdicts: COPIED = same rule as a named source. ADAPTED = a source exists but v4 changed it (the change is stated). INVENTED = no source; the rule came from this project's own sessions or plans. Project documents (/home/user/NE-IndOcc-Deaths/docs/analysis-plan.md, /home/user/NE-IndOcc-Deaths/docs/acs-denominator-spec.md, /home/user/NE-IndOcc-Deaths/docs/script-audit.md) are cited where they are the only origin, but they are not provenance: they were written in earlier sessions of this same project.

Line citations for PDFs point at the extracted text files, which carry `===== Page N =====` markers (N = PDF page). The CSTE OHI manual has no extracted text in the repo; its page numbers are PDF pages of /home/user/ohis/guidance/OHI_GuidanceManual_2019_FINAL.pdf (printed page = PDF page minus 1).

Note on the script's own header (v4 lines 8 to 9): "Death-certificate rules copy the team's SAS ... the rate method copies the Massachusetts DPH report." That is true for about half the rules below and not true for the overdose text rule, the age switch, the rate ratio, or the NIOCCS placeholder codes.

## 2. INVENTED and ADAPTED items ranked by how much they could move a published number

1. **Overdose text branch (rules 3, 4, 5, 6, 16).** Largest effect. The first real run found 68 overdoses aged 16+ that come from text only, and the 2021-2022 total (399, all ages) was above the published SUDORS 366 (/home/user/NE-IndOcc-Deaths/docs/death-cert-data-notes.md line 97). The word list is invented, misses single-drug text like "morphine toxicity", and the pasted-field and drop-list manner rules let pending and blank manners through. Provenance-backed alternative: publish the ICD branch only (SUDORS Table 2, PDF p.17), which is what every coded source uses, and carry text-only hits as a separate count for review against the SUDORS keep-list (manner A or C, Part I text, PDF p.19). If text cases are kept, apply the SUDORS rule, not v4's.
2. **Denominator choice (rules 24, 25).** Changes every rate, and unevenly by sector (part-time-heavy sectors such as accommodation and food service move most between persons and FTE). MA used ACS persons; the Nebraska team's own denominators are PUMS FTE (WKHP / 40). v4's persons choice is MA-backed; the single 5-year vintage is a project choice. Alternative with provenance on both sides: keep MA's persons as the headline and add the team's FTE formula from PUMS 2020-2024 (ESR 1 or 2, AGEP 16+, /home/user/NE-IndOcc-Deaths/team-archive/denominators/acs-pums-fte/industry/scripts/ACS.R) as a second column.
3. **Pneumoconiosis measure (rule 9).** Per 100,000 worker-years by current employment is not a measure anyone publishes for a disease of long latency whose decedents are mostly retired. Alternative: the CSTE OHI 10 measure exactly as /home/user/ohis/sub-indicators/subindicators.sas S03 already builds it (record axis, 15+, per million residents 15+, age-standardized), with industry shown as counts and percents.
4. **No manual review of NIOCCS output (rule 18).** MA "further classified by manual review" (txt line 776). Without it, NIOCCS miscodes go straight into sector counts. Alternative: MA's review, plus the team's own certificate-code crosswalk (IndustryCode x 10 through `cind2sec`, /home/user/ohis/sub-indicators/subindicators.sas lines 87-91 and 392-393) as an agreement check.
5. **Rate ratio (rule 29).** Does not change rates but drives "higher than all workers" statements. Alternative: MA's approach, a sector is called higher only when its CI lies above the all-worker rate (PDF p.4), or a rate ratio with a CI and the sector removed from the reference.
6. **Opioid subset on a SUDORS base (rule 7).** Inherits all of item 1. Alternative: the MA definition (rule 8), already computed, is the one with a published comparison.
7. **Age derivation (rule 13).** A few deaths at the 16th birthday; the NchsAge route would also admit age 999 if it were ever taken. Alternative: the SAS unit recode with 999 as missing, and exact age from dates (SAS `yrdif(..., 'AGE')`, as in /home/user/ohis/sub-indicators/subindicators.sas line 555) when NchsAge is empty.
8. **Military code list (rule 21).** Moves deaths only between no-rate rows, except that 928110 pulls civilian DoD workers out of sector 92. Alternative: MA's wording (military or military-specific occupations) with the placeholder codes checked against NIOSH's NIOCCS code documentation before publication.
9. **Exact Poisson CI (rule 28).** Widths only. Standard method, but say in the methods that MA did not state theirs.
10. **Year from date of death (rule 14)** and **not-in-workforce additions (rule 22).** Year: no expected change, since late-registered deaths are deduplicated. Additions: zero effect on any rate (they act only on records with no rate group); they change the Not in workforce versus Not coded split, which matters for the NEVDRS 84.

## 3. What the provenance does that v4 does not

- **Age adjustment.** CSTE OHI 10 age-standardizes to the US 2000 population, 15+ in 8 bands (PDF p.38-40). /home/user/ohis/sub-indicators/subindicators.sas lines 941-990 does the same for S03 totals and sex. The NE suicide dashboard maps and the 2013-2022 Vital Statistics sheet are age-adjusted. MA is crude by industry, as v4 is, so crude sector rates are defensible; but v4 has no age-adjusted statewide row to set beside the DHHS sheets.
- **Pneumoconiosis subtypes** CWP, asbestosis, silicosis, other (/home/user/ohis/sub-indicators/subindicators.sas lines 402-405; CSTE OHI 10 measures 2-5). v4 has only the total.
- **CSTE exclusions for OHI 10:** unknown age, unknown or out-of-state residence, and deaths occurring out of state (PDF p.39). v4 keeps residents who died out of state.
- **SUDORS scope:** occurrent deaths of all ages (SUDORS txt line 445), review of the literal text even for ICD-coded cases (txt lines 592-598), and exclusion of legal-intervention and medical-error overdoses (txt lines 476-481). v4 does none of these, so it cannot reproduce the SUDORS 366 by design; say so rather than tune toward it.
- **Suicide manner check.** NEVDRS classifies by manner (dashboard capture line 18); the plan asked for a manner versus ICD cross-tab (/home/user/NE-IndOcc-Deaths/docs/analysis-plan.md line 98). v4's QA does not report it (1,393 of 1,406 agree, /home/user/NE-IndOcc-Deaths/docs/death-cert-data-notes.md line 98).
- **MA extras:** year-specific rates beside the pooled rate, Joinpoint trend, race and ethnicity strata, and manual I/O review (MA PDF p.10).
- **Team FTE denominators** (PUMS WKHP / 40), the team's existing method (/home/user/NE-IndOcc-Deaths/team-archive/denominators/README.md line 60) and Derry's stated preference (/home/user/NE-IndOcc-Deaths/docs/provenance-comparison.md, section C).
- **Team SOC 11-9013 to 45 recode** (/home/user/NE-IndOcc-Deaths/team-archive/io-coding/nioccs/nioccs_suicide.R line 68). v4 is right not to apply it to the numerator alone with C24010 denominators; if the farm story is wanted, it needs a matching PUMS denominator where SOCP 119013 is moved too.
- **Certificate I/O code cross-check** (`cind2sec`, OHIs) as a second I/O method; not in v4.
- **Unknown sex.** OHIs maps other values to U and emits only M and F strata (/home/user/ohis/sub-indicators/subindicators.sas lines 96, 131). v4 keeps U deaths in the total (correct) but also writes U rows with no denominator.
- **Unknown age code.** SAS sets NchsAge 999 to missing (/home/user/ohis/sub-indicators/subindicators.sas line 382); v4's NchsAge route does not.
- **Record status check.** The SAS prints RecordStatus by year before case finding (/home/user/dc-hdd-surveillance/programs/dc/dc_condition_surveillance.sas line 34); v4 does not read RecordStatus.
- **Underlying cause in the any-mention scan.** The DC template scans 41 fields including AcmeUnderlyingCode (/home/user/dc-hdd-surveillance/programs/dc/dc_condition_surveillance.sas line 43); v4's any-mention uses 40 and leaves out the underlying code. For pneumoconiosis this only matters if a J60-J66 underlying code is missing from both axes, which should be rare.
- **ACS margin of error.** Saved by the fetch but not carried into the CI (/home/user/NE-IndOcc-Deaths/docs/acs-denominator-spec.md line 41).
